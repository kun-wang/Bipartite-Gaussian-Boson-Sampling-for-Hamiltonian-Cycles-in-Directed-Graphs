# Bipartite-Gaussian-Boson-Sampling-for-Hamiltonian-Cycles-in-Directed-Graphs
This repository contains the simulation code, fixed random seeds, numerical data, figure-generation scripts, and software-environment information used to reproduce the numerical results in the manuscript *Bipartite Gaussian Boson Sampling for Hamiltonian Cycles in Directed Graphs* (arXiv:2606.28775).
